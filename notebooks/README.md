Can Graph Neural Networks Learn PageRank?

Final degree project (TFG), Grau en Ciència de Dades Aplicada, UOC, 2026–27.

1) `notebooks/T3-T4.ipynb`: data acquisition of wiki-topcats from SNAP; topic subgraphs creation; exact PageRank calculation; train/val/test split; in-degree baseline computation; perturbed graphs creation.
2) `data/`: node and edge tables of each graph, selected categories, baseline metrics.
